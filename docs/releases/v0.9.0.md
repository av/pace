Pace 0.9.0 adds the brief: what your panels show, packed into one bounded document an agent reads once instead of browsing.

- `GET /brief.md`: Markdown for one LLM read. It covers the last 72 hours by default (`?since=24h`, `3d`, `all`, ...), deduped across panels, ranked, and capped at 40 items and 8 per panel (`?limit=`, `?per_panel=`), with `?panel=` to pick panels. Items are numbered `[n]` for citation, each with its link, source, age, score, a `why:` line and a plain-text summary.
- `GET /api/brief`: the same brief as versioned JSON (`pace.brief/v1`), documented field by field in [docs/brief.md](https://github.com/av/pace/blob/v0.9.0/docs/brief.md).
- `pace brief` (`--json`, `--panel`, `--since`, `--limit`, `--per-panel`): prints the brief from the local database, no server needed.
- `pace-brief` skill: `npx skills add av/pace --skill pace-brief`. The agent reads the brief once, cites items as `[n]`, and searches the web only for something the brief doesn't cover.

Measured on 2026-09-27 with Claude Sonnet 5 as a headless Claude Code agent, asking "what's new in ML/AI today that matters to me?" 5 times each way. With web tools and the user's source list, the agent averaged 14.6 tool calls, 51s and $0.42 per answer. Reading the `ml-ai` brief, it made one call and took 15s, for $0.03. Most of the web arm's tokens go to the small model that reads fetched pages. The web answers covered more ground and also passed off week-old launches as today's news. Script, transcripts and every answer: [scripts/brief-demo](https://github.com/av/pace/tree/v0.9.0/scripts/brief-demo).

No existing endpoint, CLI command or config key changes behaviour. Validated with 3,702 passing tests and type checking; Docker publication runs the full suite before publishing linux/amd64 and linux/arm64 images.

Docker: `ghcr.io/av/pace:0.9.0`. Pull the new tag and recreate your container to upgrade, or start fresh with `docker run -d -p 7453:7453 -v pace-data:/app/data ghcr.io/av/pace:0.9.0 --preset ml-ai` and `curl -s localhost:7453/brief.md`.
